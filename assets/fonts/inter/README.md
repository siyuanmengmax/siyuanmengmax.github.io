# Inter

Unmodified WOFF2 variable fonts from the [official Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), by the Inter Project Authors.

The English portfolio uses the upright and italic fonts, served from this site with `font-display: swap`. Chinese pages keep their system font stack.
