- 生成 52 个中英文页面：两种首页、论文、项目、代码入口、教学、动态、履历，以及项目与动态详情。

- 样式与脚本按内容哈希生成版本化文件名。字体、图片和运行脚本均为本地静态资源，构建不请求网络。
