FRGB3D

面向路侧激光雷达交通监测的快速可靠性加权高斯背景建模

论文状态： 已发表 · Journal of Computing in Civil Engineering, 41(1), 04026129 (2027)

GitHub 代码 ↗

背景消除是激光雷达交通监测的基础环节。距离、表面反射率与大气条件导致的测量可靠性差异，增加了背景与前景分离的难度。

FRGB3D 提出适用于路侧激光雷达点云的快速可靠性加权高斯背景模型：

  • 基于测距与反射率特征，构建具有物理依据的测量可靠性指标
  • 依据点的可靠性自适应调整背景模型学习率
  • 结合测量可靠性与模型学习得到的不确定性，自适应设置前景检测阈值

研究采用 CARLA 仿真与美国马萨诸塞州洛厄尔市的实测激光雷达数据，评估不同天气与交通条件下的性能。实测实验处理速度达到 19.1 帧/秒，无需标注训练数据或 GPU 硬件，支持实际路侧交通监测应用。
